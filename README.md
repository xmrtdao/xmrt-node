# XMRT Node

**AI-orchestrated Monero mining node.** One codebase for Android, XMRT Charger, and XMRT Stick.

Deploy a living MobileMonero node from the Play Store. Your phone becomes a fleet ship — mining, reporting, and coordinating through the XMRT-DAO mesh network.

## Quick Start

```bash
git clone --recurse-submodules https://github.com/xmrtdao/xmrt-node.git
cd xmrt-node
flutter build apk --release
```
